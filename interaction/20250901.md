## 오늘 배운 내용: 3D 리플릿만들기 번들링
- HTMLWebpackPlugin
     - HTML파일을 템플릿으로 등록해두면, 웹팩이 알아서 필요한 JavaScript와 CSS파일을 자동으로 삽입해준다.
     - SPA를 devServer로 사용해주고싶을때, 이 플러그인이 있어야만, 매번 새로 갱신된 js를 index.html이 삽입하여 핫업데이트가 가능해진다
- Asset Modules
     - 이미지나 폰트같은 정적자원을 모듈로 `import`하게 해주는 속성
     - 다만 `typescript`와 같이 사용할 경우 별도의 `declare`선언 필요
          - asset/resource: 정적 파일을 별도 파일로 내보내고 URL 반환
          - asset/inline: 파일을 base64로 인코딩된 data URL로 반환
          - asset/source: 파일의 내용을 문자열로 반환
          - asset: 파일 크기에 따라 자동으로 resource, inline 선택

     - 작은 이미지의 경우 문자열로 번들에 포함시켜 이미지 로딩속도를 단축시킬 수 있지만, 폰트는 용량이 크기때문에 별도 파일로 보내 브라우저 캐시를 활용하는게 효율적
