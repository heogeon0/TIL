- requestAnimationFrame
     - 강의에서도 배우고 정리했었는데, react로 변경하면서 또 헷갈린 부분이 있었다.
     - `requestAnimationFrame`은 모니터주사율에 맞춰 한번 실행된다. 즉, 연속적으로 실행시키고자할때는 재귀적구조를 통해서 구현해야한다.
     ```tsx
     useEffect(() => {
     const handleRequestAnimationFrameForHandMove = () => {
          const hand = handRef.current;
          if (!hand) return;
          
          handPos.x = handPos.x + (targetPos.x - handPos.x) * 0.1;
          handPos.y = handPos.y + (targetPos.y - handPos.y) * 0.1;
          hand.style.transform = `translate(${handPos.x-60}px, ${handPos.y+30}px)`;
          
          requestAnimationFrameRef.current= requestAnimationFrame(handleRequestAnimationFrameForHandMove);
     }

     handleRequestAnimationFrameForHandMove();

     
     return () => {
          if (requestAnimationFrameRef.current) {
          cancelAnimationFrame(requestAnimationFrameRef.current);
          }
     }

     }, [handPos, handRef, targetPos])
     ```
