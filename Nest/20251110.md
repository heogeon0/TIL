## 📝 배운 내용

### 키워드
#### 상세 내용
- Nest.js의 특징
	- **TypeScript 기반**: Express를 기반으로 만들어졌으며, TypeScript를 기본으로 사용하여 강력한 타입 안정성 제공
	- **모듈러 아키텍처**: 모듈에 대한 의존성이 명확하고, 기능별로 모듈을 분리하여 확장 가능한 구조
	- **DI (Dependency Injection)**: 의존성 주입 패턴을 프레임워크 레벨에서 지원하여 테스트와 유지보수가 용이
	- **AOP (Aspect Oriented Programming)**: Interceptor, Guard, Pipe 등을 통한 관점 지향 프로그래밍 지원
	- **데코레이터 패턴**: @Controller, @Injectable, @Module 등 데코레이터를 활용한 직관적인 코드 작성
	- **Express/Fastify 지원**: 내부적으로 Express 또는 Fastify를 선택해서 사용 가능
	- **테스트 친화적**: Jest를 기본 테스트 프레임워크로 채택하고, 유닛 테스트와 E2E 테스트 지원
	- **마이크로서비스 지원**: TCP, Redis, MQTT, gRPC 등 다양한 전송 계층 지원
	- **다양한 프로토콜**: REST API, GraphQL, WebSocket, Server-Sent Events 등 지원
	- **강력한 CLI**: 프로젝트 생성, 모듈/컨트롤러 생성 등을 쉽게 할 수 있는 CLI 도구 제공
	- **Angular와 유사한 구조**: Angular 개발 경험이 있다면 쉽게 적응 가능한 구조
	- **미들웨어 체인**: Express의 미들웨어를 그대로 사용 가능하며, Nest만의 미들웨어 시스템도 제공
