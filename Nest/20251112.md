## 📝 배운 내용

#### 상세 내용

- **NestJS Hot Module Replacement (HMR)**
	- 코드 수정 시 서버를 재시작하지 않고 변경사항을 즉시 반영
	- 개발 속도를 빠르게 해주는 기능
	- Webpack의 HMR 기능을 활용

	**HMR 설정 방법**
	- nest 11버전 기준 설치후 `webpack-hmr.config.js` 등록
	- 해당 웹팩 경로로 실행
	- [설정링크](https://docs.nestjs.com/recipes/hot-reload)

- **NestJS Controller (컨트롤러)**
	- Express의 라우터와 유사한 역할
	- 클라이언트 요청을 받아서 응답을 반환하는 역할
	- **데코레이터**를 사용해서 라우팅 자동 매칭

	**데코레이터란?**
	- `@` 기호로 시작하는 특별한 선언
	- 클래스, 메서드, 프로퍼티에 메타데이터를 추가
	- NestJS가 이 정보를 읽고 자동으로 라우팅 설정 (제어의 역전)

	**Controller 기본 예제**
	```typescript
	import { Controller, Get, Post, Body, Param } from '@nestjs/common';

	@Controller('users')  // /users 경로의 기본 라우트
	export class UsersController {

	  @Get()  // GET /users
	  findAll() {
	    return '모든 사용자 조회';
	  }

	  @Get(':id')  // GET /users/:id
	  findOne(@Param('id') id: string) {
	    return `사용자 ${id} 조회`;
	  }

	  @Post()  // POST /users
	  create(@Body() userData: any) {
	    return `사용자 생성: ${JSON.stringify(userData)}`;
	  }
	}
	```

	**주요 데코레이터**
	- `@Controller()`: 컨트롤러 클래스 정의
	- `@Get()`: GET 요청 처리
	- `@Post()`: POST 요청 처리
	- `@Put()`: PUT 요청 처리
	- `@Delete()`: DELETE 요청 처리
	- `@Param()`: URL 파라미터 추출
	- `@Body()`: 요청 본문 추출
	- `@Query()`: 쿼리 스트링 추출

	**Express vs NestJS 비교**
	```javascript
	// Express
	app.get('/users/:id', (req, res) => {
	  const id = req.params.id;
	  res.send(`사용자 ${id} 조회`);
	});

	// NestJS
	@Get(':id')
	findOne(@Param('id') id: string) {
	  return `사용자 ${id} 조회`;
	}
	```
