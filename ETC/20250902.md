# TIL - 20250902 개발환경 셋팅

## 키워드
심볼릭 링크를 활용한 개발 활용 셋팅

## 오늘 배운 내용
- 효율적인 창관리를 위한 aerospace 적용 및 설정 커스텀
- 심볼릭 링크를 활용한 config 공유
     - `ln -s ~/Library/Mobile\ Documents/com~apple~CloudDocs/Configs/AeroSpace/.aerospace.toml ~/.aerospace.toml`
     - `ln -s ~/Library/Mobile\ Documents/com~apple~CloudDocs/kitty/kitty.conf ~/.config/kitty/kitty.conf`
     - `ln -s ~/Library/Mobile\ Documents/com~apple~CloudDocs/zsh/.zshrc ~/.zshrc`

## 더 공부해야할 내용
- 빠른 개발 생산성을 위해 나만의 개발 환경을 구축하고 어디서나 활용할 수 있도록 잘 셋팅을 해두어야겠다.
