# TIL - 20250921 한입크기로 잘라먹는 Next.js

## 키워드
NEXT.JS,API, 스타일링, 레이아웃

## 오늘 배운 내용
- 글로벌 스타일링
     - NEXT에서 글로벌 css는 항상 _app에서만 불러야함

- 레이아웃
     - 글로벌 레이아웃을 정의할려면 모든 페이지의 부모컴포넌트인 _app 폴더에 적용하면됨
     - 개별 레이아웃을 정의하기 위해서는 `getLayout`와 같이 메서드를 활용하여 레이아웃 정의가능
          - `_app`에서 `getLayout`의 존재여부를 처리하여, 존재할경우 레이아웃을 적용 후 렌더가능2323
     

- 프리패칭
     - Link로 연결되어있는 페이지를 사전에 불러놓는 기능(Dev 환경에서는 동작하지않음)
     - NEXT는 초기 요청시, 사전에 만들어놓은 index.html과 해당 페이지의 js bundle을 주게됨
          - 그 후, SPA처럼 동작하기위해 해당 페이지와 Link로 연결된 페이지의 js bundle은 미리 패치하는 작업
          - `router.push`같이 programtic router에 대응하기 위해서는 
               ```
               useEffect(() => {
                    router.prefetch("test")
               })
               ```
               와 같은 prefetch 명령어 수행
