 
 # TIL - 한입크기로 잘라먹는 Next.js

## 키워드
NEXT.JS, APP router

## 오늘 배운 내용
- app router의 페이지 라우팅
     - page: ~/ 경로의 페이지가됨
          - 폴더안에 꼭 page 파일이 있어야 라우팅이 생성됨
          - query string은 `props`로 `searchParams`값으로 전달이됨
               - 다만 `Promise`형태로 전달되기 때문에 `async/await`구문으로 작성되어야함
               - 리액트의 서버컴포넌트는 `async/await` 사용 가능
          - url params 역시 `async/await` 형태로 들어옴
     - layout
          - 폴더안에 `layout.tsx`가 있으면 자동으로 레이아웃이 적용됨
          - 가장 하단에 `layout.tsx`파일을 `RootLayout`파일이있으며 모든 페이지에 동일하게 적용되는 레이아웃임
          - `children`을 `page component`를 받음
          - 경로와 상관없이 공통 레이아웃을 가지고 싶은 경우
               - route group을 사용(소괄호를 사용한 폴더)
               - 경로상에는 아무 영향을 미치지 않지만, 레이아웃을 공통적으로 적용하는 경우 용이
