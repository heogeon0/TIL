## 키워드
#NEXT #사전렌더링 #데이터패치
## 오늘 배운 내용
- ISR
     - 특정 시간이 지난 후 새로운 요청이 오는경우, 새로 데이터를 받아와 페이지를 갱신
          - SSG의 장점과 SSR의 장점을 가지고있음
     - onDemandISR
          - 특정 시간마다 페이지를 갱신하는게 아닌 조건에 따라, 재검증하는 것
          - `NextApiResponse`의 `revalidate`메서드를 활용해서 특정 페이지 정보를 갱신할 수 있음
- Page Router 정리
     - 장점
          1. 파일시스템 기반의 간편한 페이지 라우팅 제공
          2. 다양한 방식의 사전 렌더링 제공
     - 단점
          1. 데이터 패칭이 Page페이지에만 집중됨
          2. 레이아웃을 지정할 때 중복코드가 들어감
          3. 불필요한 컴포넌트도 JS Bundle에 포함됨
               - 사전렌더링 과정에 사용된 JS컴포넌트도 포함되어 제공됨
