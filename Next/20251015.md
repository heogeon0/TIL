 
 # TIL - 한입크기로 잘라먹는 Next.js

## 키워드
NEXT.JS, 스트리밍

## 오늘 배운 내용
- 스트리밍
     - 서버에서 보내줄 데이터가 많은 경우 데이터를 작게 쪼개어 연속적으로 보내는 기법
     - 특정 페이지를 렌더링할때, 비동기동작이 필요없어서 빨리 렌더링 될수 있는 컴포넌트 먼저 보내주면서 렌더링
     - `loading.tsx`가 존재한다면 자동으로 streaming 이 적용됨
          - 하위경로에 비동기 페이지가있다면 자동으로 streaming이 적용되며, 대체 ui도 동일하게 보임
     - 컴포넌트도 streaming을 적용하기 위해서는 리액트의 suspense를 사용해야함
     - 컴포넌트마다 적용할 수 있다는 장점때문에, `loading`을 사용하는것보다 더 선호되는 경향이 있음
