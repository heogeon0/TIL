## 오늘 배운 내용
- 동적 segment
     - Catch-all ([...slug])
          - /blog/a, /blog/a/b 등 하위 경로만 매칭
          - /blog 자체는 404 에러
          - params는 항상 문자열 배열
     - Optional Catch-all ([[...slug]])
          - /blog, /blog/a, /blog/a/b 모두 매칭
          - 상위 경로에서는 params가 undefined 또는 빈 배열
          - 하나의 파일로 목록 페이지와 상세 페이지를 모두 처리 가능

- 프리패칭
     - Link로 연결되어있는 페이지를 사전에 불러놓는 기능(Dev 환경에서는 동작하지않음)
     - NEXT는 초기 요청시, 사전에 만들어놓은 index.html과 해당 페이지의 js bundle을 주게됨
          - 그 후, SPA처럼 동작하기위해 해당 페이지와 Link로 연결된 페이지의 js bundle은 미리 패치하는 작업
          - `router.push`같이 programtic router에 대응하기 위해서는 
               ```
               useEffect(() => {
                    router.prefetch("test")
               })
               ```
               와 같은 prefetch 명령어 수행
