 
 # TIL - 한입크기로 잘라먹는 Next.js

## 키워드
#NEXT #데이터패칭방법의변경

## 오늘 배운 내용
- Server Component
     - 서버 컴포넌트는 서버에서만 실행되기 때문에 `async/await` 문법과 함께 `fetch`를 활용하여 데이터 패칭
          - Next에서는 필요한곳에서 호출하는 것을 권장
- Data Cache
     - no-store: 캐시 동작을 하지 않음
     - force-cache: 한번 호출 된 이후로는 다시 캐시되지 않음 (반드시 캐시)
     - {next: {revalidate: number}}: number초 까지 캐시
- 리퀘스트 메모이제이션
     - 여러개의 컴포넌트에서 동일한 요청을 하는 경우 중복호출을 방지하는 기능
     - 데이터 캐시와는 다른 동작 / 각 페이지마다 동작하기 때문에, 다른 페이지로 이동한 경우에는 메모이제이션 되지 않음


참고: next config에 로깅 방법
```
logging: {
     fetches: {
          fullUrl: true
     }
}
```
