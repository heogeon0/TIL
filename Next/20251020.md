 
 # TIL - 한입크기로 잘라먹는 Next.js

## 키워드
NEXT.JS, 컴포넌트 스트리밍

## 오늘 배운 내용
- 컴포넌트 스트리밍
     - `Suspense`를 활용해서 컴포넌트 단위로 스트리밍이 가능
     - 브라우저에서 새로 로딩상태에 들어갔을 때 로딩화면이 안나오는 경우를 쉽게 대응가능
          - `Suspense`에 key에 값을 넣어줄경우 `key`값이 바뀔 때마다 로딩 UI표시
          - `Suspense`에 key를 바꾸어 새로운 컴포넌트로 그리도록 하는것
               - `Suspense`는 한번 로드 후 새로 로드되지않음
