## LangChain이란?
- LLM 기반 애플리케이션과 Agent를 빠르고 쉽게 개발할 수 있는 프레임워크

### 핵심 메소드
#### 1. invoke() - 단일 응답
```javascript
import { ChatOpenAI } from "@langchain/openai";

const model = new ChatOpenAI({
  model: "gpt-4",
  temperature: 0.7,  // 창의성 (0~1)
  maxTokens: 1000,   // 최대 토큰 수
  timeout: 30000,    // 타임아웃 (ms)
  maxRetries: 2      // 재시도 횟수
});

// 단일 질문-답변
const response = await model.invoke("안녕하세요! LangChain에 대해 설명해주세요.");
console.log(response.content);
```

#### 2. stream() - 스트리밍 응답
```javascript
// chunk 단위로 잘라서 답변 생성
const stream = await model.stream("긴 이야기를 들려주세요.");

for await (const chunk of stream) {
  console.log(chunk.content); // 실시간으로 텍스트 출력
}
```

#### 3. batch() - 병렬 처리
```javascript
// 여러 질문을 병렬적으로 요청
const questions = [
  "LangChain이란?",
  "OpenAI API 사용법은?",
  "프롬프트 엔지니어링 팁은?"
];

const responses = await model.batch(questions);
responses.forEach((response, index) => {
  console.log(`질문 ${index + 1}: ${questions[index]}`);
  console.log(`답변: ${response.content}\n`);
});
```


### 구조화된 답변 생성 (Structured Outputs)
```javascript
import { ChatOpenAI } from "@langchain/openai";
import { z } from "zod";

const model = new ChatOpenAI({ model: "gpt-4" });

// Zod 스키마 정의
const PersonSchema = z.object({
  name: z.string().describe("사람의 이름"),
  age: z.number().describe("사람의 나이"),
  occupation: z.string().describe("직업")
});

// 구조화된 출력 설정
const structuredModel = model.withStructuredOutput(PersonSchema);

const response = await structuredModel.invoke(
  "홍길동은 30살이고 소프트웨어 엔지니어입니다."
);

console.log(response);
// { name: "홍길동", age: 30, occupation: "소프트웨어 엔지니어" }
```

### Chain (체인)
여러 컴포넌트를 연결하여 복잡한 워크플로우 구성

```javascript
import { ChatOpenAI } from "@langchain/openai";
import { ChatPromptTemplate } from "@langchain/core/prompts";
import { StringOutputParser } from "@langchain/core/output_parsers";

// 1. LCEL (LangChain Expression Language)을 사용한 체인
const model = new ChatOpenAI({ model: "gpt-4" });
const promptTemplate = ChatPromptTemplate.fromMessages([
  ["system", "당신은 번역 전문가입니다."],
  ["human", "{text}를 {language}로 번역해주세요."]
]);
const outputParser = new StringOutputParser();

// 파이프(|) 연산자로 체인 구성
const chain = promptTemplate.pipe(model).pipe(outputParser);

// 실행
const result = await chain.invoke({
  text: "Hello, how are you?",
  language: "한국어"
});
console.log(result); // "안녕하세요, 어떻게 지내세요?"


// 2. 순차 체인 (Sequential Chain)
const translateChain = ChatPromptTemplate.fromTemplate(
  "{text}를 영어로 번역하세요"
).pipe(model).pipe(outputParser);

const summaryChain = ChatPromptTemplate.fromTemplate(
  "다음 텍스트를 한 문장으로 요약하세요: {translatedText}"
).pipe(model).pipe(outputParser);

// 체인 조합
async function translateAndSummarize(text) {
  const translated = await translateChain.invoke({ text });
  const summary = await summaryChain.invoke({ translatedText: translated });
  return summary;
}

const result2 = await translateAndSummarize(
  "오늘은 날씨가 좋아서 공원에 산책을 갔습니다. 많은 사람들이 있었고 즐거운 시간을 보냈습니다."
);
```

### 메모리 구현
대화 컨텍스트를 유지하여 이전 대화를 기억하는 챗봇 구현

```javascript
import { ChatOpenAI } from "@langchain/openai";
import { ChatPromptTemplate, MessagesPlaceholder } from "@langchain/core/prompts";
import { RunnableWithMessageHistory } from "@langchain/core/runnables";
import { ChatMessageHistory } from "langchain/stores/message/in_memory";

// 1. 메시지 객체를 사용한 대화
const model = new ChatOpenAI({ model: "gpt-4" });

const conversationHistory = [
  { role: "system", content: "당신은 친절한 AI 어시스턴트입니다." },
  { role: "human", content: "내 이름은 철수야" },
  { role: "ai", content: "안녕하세요 철수님!" },
  { role: "human", content: "내 이름이 뭐였지?" }
];

const response = await model.invoke(conversationHistory);
console.log(response.content); // "철수님이라고 하셨습니다."


// 2. ChatMessageHistory를 사용한 메모리 관리
const messageHistory = new ChatMessageHistory();

// 대화 추가
await messageHistory.addUserMessage("안녕하세요! 오늘 날씨 어때요?");
await messageHistory.addAIMessage("안녕하세요! 오늘은 맑고 화창한 날씨입니다.");

// 대화 기록 조회
const messages = await messageHistory.getMessages();
console.log(messages);


// 3. RunnableWithMessageHistory로 자동 메모리 관리
const sessionStore = {};

const prompt = ChatPromptTemplate.fromMessages([
  ["system", "당신은 대화 내용을 기억하는 친절한 AI입니다."],
  new MessagesPlaceholder("history"),
  ["human", "{input}"]
]);

const chain = prompt.pipe(model);

const chainWithHistory = new RunnableWithMessageHistory({
  runnable: chain,
  getMessageHistory: async (sessionId) => {
    if (!sessionStore[sessionId]) {
      sessionStore[sessionId] = new ChatMessageHistory();
    }
    return sessionStore[sessionId];
  },
  inputMessagesKey: "input",
  historyMessagesKey: "history"
});

// 세션별 대화
const config = { configurable: { sessionId: "user123" } };

await chainWithHistory.invoke(
  { input: "내 이름은 영희야" },
  config
);

const response2 = await chainWithHistory.invoke(
  { input: "내 이름이 뭐였지?" },
  config
);
console.log(response2.content); // "영희라고 하셨습니다."
```

## Agent 기초
### Tools (도구)
AI가 외부 기능을 호출할 수 있게 하는 인터페이스

```javascript
import { ChatOpenAI } from "@langchain/openai";
import { DynamicStructuredTool } from "@langchain/core/tools";
import { z } from "zod";

// 1. 커스텀 도구 정의
const weatherTool = new DynamicStructuredTool({
  name: "get_weather",
  description: "특정 도시의 현재 날씨를 가져옵니다",
  schema: z.object({
    city: z.string().describe("도시 이름"),
  }),
  func: async ({ city }) => {
    // 실제로는 API 호출
    const weatherData = {
      "서울": "맑음, 15도",
      "부산": "흐림, 18도"
    };
    return weatherData[city] || "날씨 정보 없음";
  }
});

const calculatorTool = new DynamicStructuredTool({
  name: "calculator",
  description: "수학 계산을 수행합니다",
  schema: z.object({
    expression: z.string().describe("계산할 수식 (예: 2 + 2)"),
  }),
  func: async ({ expression }) => {
    try {
      // 주의: 실제 프로덕션에서는 안전한 계산 방법 사용
      const result = eval(expression);
      return `결과: ${result}`;
    } catch (error) {
      return "계산 오류";
    }
  }
});

// 2. 도구를 모델에 바인딩
const model = new ChatOpenAI({ model: "gpt-4" });
const modelWithTools = model.bindTools([weatherTool, calculatorTool]);

// 3. 도구 호출
const response = await modelWithTools.invoke("서울 날씨 어때?");

// AI가 도구 호출 요청
if (response.tool_calls && response.tool_calls.length > 0) {
  const toolCall = response.tool_calls[0];
  console.log("AI가 호출할 도구:", toolCall.name);
  console.log("파라미터:", toolCall.args);

  // 도구 실행
  const toolResult = await weatherTool.invoke(toolCall.args);
  console.log("도구 실행 결과:", toolResult);
}


// 4. Agent Executor로 자동 도구 호출
import { AgentExecutor, createToolCallingAgent } from "langchain/agents";
import { ChatPromptTemplate } from "@langchain/core/prompts";

const prompt = ChatPromptTemplate.fromMessages([
  ["system", "당신은 유용한 어시스턴트입니다. 필요한 경우 도구를 사용하세요."],
  ["human", "{input}"],
  ["placeholder", "{agent_scratchpad}"]
]);

const agent = await createToolCallingAgent({
  llm: model,
  tools: [weatherTool, calculatorTool],
  prompt
});

const agentExecutor = new AgentExecutor({
  agent,
  tools: [weatherTool, calculatorTool]
});

// 자동으로 도구를 호출하고 결과를 반환
const result = await agentExecutor.invoke({
  input: "서울 날씨를 알려주고, 15 곱하기 3을 계산해줘"
});

console.log(result.output);
// "서울은 현재 맑음, 15도입니다. 15 곱하기 3은 45입니다."
```

## RAG (Retrieval Augmented Generation)
문서를 검색하여 LLM에 컨텍스트로 제공, 더 정확한 답변 생성

```javascript
import { ChatOpenAI } from "@langchain/openai";
import { OpenAIEmbeddings } from "@langchain/openai";
import { MemoryVectorStore } from "langchain/vectorstores/memory";
import { ChatPromptTemplate } from "@langchain/core/prompts";
import { createStuffDocumentsChain } from "langchain/chains/combine_documents";
import { createRetrievalChain } from "langchain/chains/retrieval";
import { Document } from "@langchain/core/documents";

// 1. 문서 준비
const documents = [
  new Document({
    pageContent: "LangChain은 LLM 애플리케이션 개발 프레임워크입니다.",
    metadata: { source: "docs1" }
  }),
  new Document({
    pageContent: "LangChain은 체인, 에이전트, 메모리 등의 기능을 제공합니다.",
    metadata: { source: "docs2" }
  }),
  new Document({
    pageContent: "RAG는 검색 증강 생성 기법으로, 외부 지식을 활용합니다.",
    metadata: { source: "docs3" }
  })
];

// 2. 벡터 스토어 생성 (임베딩 + 저장)
const embeddings = new OpenAIEmbeddings();
const vectorStore = await MemoryVectorStore.fromDocuments(
  documents,
  embeddings
);

// 3. Retriever 생성
const retriever = vectorStore.asRetriever({
  k: 2 // 상위 2개 문서 검색
});

// 4. RAG 체인 구성
const model = new ChatOpenAI({ model: "gpt-4" });

const prompt = ChatPromptTemplate.fromTemplate(`
다음 컨텍스트를 사용하여 질문에 답변하세요:

{context}

질문: {input}
`);

const documentChain = await createStuffDocumentsChain({
  llm: model,
  prompt
});

const retrievalChain = await createRetrievalChain({
  combineDocsChain: documentChain,
  retriever
});

// 5. 실행
const result = await retrievalChain.invoke({
  input: "LangChain이 제공하는 기능은 무엇인가요?"
});

console.log(result.answer);
// "LangChain은 체인, 에이전트, 메모리 등의 기능을 제공합니다."

// 검색된 문서 확인
console.log("참조한 문서:", result.context);


// 6. 실전 예제: PDF 문서 기반 QA 시스템
import { PDFLoader } from "langchain/document_loaders/fs/pdf";
import { RecursiveCharacterTextSplitter } from "langchain/text_splitter";

async function createPDFQASystem(pdfPath) {
  // PDF 로드
  const loader = new PDFLoader(pdfPath);
  const docs = await loader.load();

  // 문서 분할 (큰 문서를 작은 청크로)
  const textSplitter = new RecursiveCharacterTextSplitter({
    chunkSize: 1000,
    chunkOverlap: 200
  });
  const splitDocs = await textSplitter.splitDocuments(docs);

  // 벡터 스토어 생성
  const vectorStore = await MemoryVectorStore.fromDocuments(
    splitDocs,
    new OpenAIEmbeddings()
  );

  // RAG 체인 생성
  const retriever = vectorStore.asRetriever();
  const chain = await createRetrievalChain({
    combineDocsChain: await createStuffDocumentsChain({
      llm: new ChatOpenAI({ model: "gpt-4" }),
      prompt: ChatPromptTemplate.fromTemplate(`
        다음 문서 내용을 참고하여 답변하세요:
        {context}

        질문: {input}
      `)
    }),
    retriever
  });

  return chain;
}

// 사용
const qaChain = await createPDFQASystem("./document.pdf");
const answer = await qaChain.invoke({
  input: "이 문서의 주요 내용은 무엇인가요?"
});
```

### 1. 고객 지원 챗봇 (메모리 + Tools)
```javascript
import { ChatOpenAI } from "@langchain/openai";
import { DynamicStructuredTool } from "@langchain/core/tools";
import { ChatMessageHistory } from "langchain/stores/message/in_memory";
import { RunnableWithMessageHistory } from "@langchain/core/runnables";
import { ChatPromptTemplate, MessagesPlaceholder } from "@langchain/core/prompts";
import { AgentExecutor, createToolCallingAgent } from "langchain/agents";
import { z } from "zod";

// 주문 조회 도구
const orderTool = new DynamicStructuredTool({
  name: "get_order_status",
  description: "주문 번호로 주문 상태를 조회합니다",
  schema: z.object({
    orderId: z.string().describe("주문 번호")
  }),
  func: async ({ orderId }) => {
    // 실제로는 DB 조회
    const orders = {
      "12345": "배송 중",
      "67890": "배송 완료"
    };
    return orders[orderId] || "주문을 찾을 수 없습니다";
  }
});

// 환불 처리 도구
const refundTool = new DynamicStructuredTool({
  name: "process_refund",
  description: "주문 번호로 환불을 처리합니다",
  schema: z.object({
    orderId: z.string().describe("주문 번호"),
    reason: z.string().describe("환불 사유")
  }),
  func: async ({ orderId, reason }) => {
    return `주문 ${orderId}에 대한 환불이 접수되었습니다. 사유: ${reason}`;
  }
});

const model = new ChatOpenAI({ model: "gpt-4" });
const tools = [orderTool, refundTool];

const prompt = ChatPromptTemplate.fromMessages([
  ["system", "당신은 친절한 고객 지원 상담원입니다. 고객의 문의를 해결해주세요."],
  new MessagesPlaceholder("history"),
  ["human", "{input}"],
  new MessagesPlaceholder("agent_scratchpad")
]);

const agent = await createToolCallingAgent({ llm: model, tools, prompt });
const agentExecutor = new AgentExecutor({ agent, tools });

// 세션 관리
const sessions = {};
const agentWithHistory = new RunnableWithMessageHistory({
  runnable: agentExecutor,
  getMessageHistory: async (sessionId) => {
    if (!sessions[sessionId]) {
      sessions[sessionId] = new ChatMessageHistory();
    }
    return sessions[sessionId];
  },
  inputMessagesKey: "input",
  historyMessagesKey: "history"
});

// 사용 예시
const config = { configurable: { sessionId: "customer_001" } };

await agentWithHistory.invoke(
  { input: "주문 번호 12345 상태 확인해주세요" },
  config
);

await agentWithHistory.invoke(
  { input: "그 주문 환불하고 싶어요. 사이즈가 안 맞아서요" },
  config
);
// Agent가 이전 대화를 기억하고 주문번호 12345에 대한 환불 처리
```

### 2. 다국어 문서 분석 시스템 (RAG + Chain)
```javascript
import { ChatOpenAI } from "@langchain/openai";
import { OpenAIEmbeddings } from "@langchain/openai";
import { MemoryVectorStore } from "langchain/vectorstores/memory";
import { Document } from "@langchain/core/documents";
import { ChatPromptTemplate } from "@langchain/core/prompts";
import { StringOutputParser } from "@langchain/core/output_parsers";

async function createMultilingualDocAnalyzer(documents) {
  // 벡터 스토어 생성
  const vectorStore = await MemoryVectorStore.fromDocuments(
    documents,
    new OpenAIEmbeddings()
  );

  const retriever = vectorStore.asRetriever({ k: 3 });
  const model = new ChatOpenAI({ model: "gpt-4" });

  // 체인 1: 문서 검색 + 답변 생성
  const qaPrompt = ChatPromptTemplate.fromTemplate(`
    다음 문서를 참고하여 질문에 답변하세요:
    {context}

    질문: {question}
    답변 언어: {language}
  `);

  const qaChain = qaPrompt
    .pipe(model)
    .pipe(new StringOutputParser());

  // 체인 2: 요약
  const summaryPrompt = ChatPromptTemplate.fromTemplate(`
    다음 텍스트를 {language}로 요약하세요:
    {text}
  `);

  const summaryChain = summaryPrompt
    .pipe(model)
    .pipe(new StringOutputParser());

  return {
    async ask(question, language = "한국어") {
      // 관련 문서 검색
      const docs = await retriever.invoke(question);
      const context = docs.map(d => d.pageContent).join("\n\n");

      // 답변 생성
      return await qaChain.invoke({ context, question, language });
    },

    async summarize(text, language = "한국어") {
      return await summaryChain.invoke({ text, language });
    }
  };
}

// 사용
const docs = [
  new Document({ pageContent: "AI technology is advancing rapidly..." }),
  new Document({ pageContent: "Machine learning requires large datasets..." })
];

const analyzer = await createMultilingualDocAnalyzer(docs);

const answer = await analyzer.ask(
  "What is machine learning?",
  "한국어"
);

const summary = await analyzer.summarize(
  "Long English text...",
  "한국어"
);
```

## 📝 배운 내용

#### 핵심 개념
- **LangChain**: LLM 애플리케이션 개발을 위한 통합 프레임워크
- **Chain**: 여러 컴포넌트를 연결하여 복잡한 워크플로우 구성 (LCEL 사용)
- **Agent**: 도구(Tools)를 활용하여 동적으로 작업을 수행하는 시스템
- **Memory**: 대화 컨텍스트를 유지하여 이전 대화를 기억
- **RAG**: 외부 문서를 검색하여 LLM에 컨텍스트로 제공, 정확도 향상

#### 주요 기능
1. **기본 메소드**: invoke (단일), stream (스트리밍), batch (병렬)
2. **Prompt Template**: 재사용 가능한 프롬프트 관리
3. **Structured Output**: Zod 스키마를 사용한 타입 안전 출력
4. **Tools**: AI가 외부 기능(API, DB 등)을 호출할 수 있게 함
5. **Vector Store**: 문서 임베딩 및 유사도 검색

---

## 💡 인사이트 & 깨달음

- LangChain의 핵심은 **조합(Composition)**이다. 작은 컴포넌트를 연결하여 복잡한 시스템 구축
- **RAG**는 LLM의 hallucination을 줄이고 최신 정보를 제공하는 핵심 패턴
- **Agent + Tools**로 LLM이 단순 텍스트 생성을 넘어 실제 작업을 수행 가능
- **메모리 관리**는 자연스러운 대화형 애플리케이션의 필수 요소
- LCEL(LangChain Expression Language)의 pipe 연산자가 코드 가독성을 크게 향상
