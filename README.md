---

## ✍️ 작성 방법

1. **템플릿 사용**: `template.md` 복사
2. **파일명**: `YYYYMMDD.md` 형식 (예: `20251110.md`)
3. **주제별 폴더**: 해당 기술 스택 폴더에 저장
4. **태그 활용**: `#tech/nextjs` `#category/frontend`

## 📋 작성 원칙

### DO ✅
- 배운 핵심 개념 정리
- 코드 예제 포함
- 막혔던 부분과 해결 과정
- 다음에 학습할 내용

### DON'T ❌
- 단순 복붙만 하기
- 너무 완벽하게 쓰려고 하기
- 안 쓰는 것보다는 조금이라도 쓰기!
