# TIL - 피그마 컴포넌트, 프로퍼티

## 키워드
#Figma #Component #Properties #NestedInstance

## 오늘 배운 내용
- 피그마에서 컴포넌트와 프로퍼티를 만드는법, 그리고 중첩컴포넌트에서 사용되는 Nested Instance를 공부함
- shift+a: 오토레이아웃, option + cmd + k: 컴포넌트 생성 단축키 익힘
- 피그마 프로퍼티를 공부하면 프론트엔드의 CDD와 매우 유사하다는것을 느낄수있었음. 피그마를 잘 활용할수 있다면, UI컴포넌트 만드는건 쉽게 가능할 수도 있다는 생각이 들었음
