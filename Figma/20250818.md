# TIL - 피그마 컴포넌트, 프로퍼티

## 키워드

## 오늘 배운 내용
- 피그마 컴포넌트 기능을 활용하여 인풋 컴포넌트 직접 개발
- 프론트에서 인풋을 만들때 들어가는 props와 거의 유사했음. 이거를 잘 만든다면, input을 반복적으로 작업할 일이 없을거라 생각됨
- 플러그인 추천: detach Component(컴포넌트 제거), Instance Finder(인스턴스 사용처 발견), Propster(내가 정의한 프로퍼티의 모든 버전을 보여줌)
